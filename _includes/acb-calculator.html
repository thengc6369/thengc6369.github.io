Calculate the ACB-index from MDGMs

Upload 1–50 Mars Daily Global Maps (MDGM V2 database). Each image receives an ACB-index point in the phase-space diagram.

Input: unmodified, full-globe RGB PNGs, each 3600 × 1801 pixels, longitude 0–360° left to right, latitude 90°N–90°S top to bottom. Preserve the original 8-bit blue-channel brightness.

ACB-index filtering:

The causal mean averages each calculated ACB-index component over the current image and up to four previous images in the selected file order. For images 1–4 it uses the available images only. The individual unfiltered values are preserved in the results and CSV.
